# Discovery: the brand is known, the content is not

GWAI's look and voice live in [gwai-brand.md](gwai-brand.md) and `videos/BRAND.md`. Discovery for a GWAI film is about the content: what the film is about, what she sent, and which facts are real.

## 1. The profile

Read `videos/BRAND.md`. If it is missing, `setup.mjs` writes it from `templates/BRAND.md`; read that. Note the standing choices and every note from past films.

## 2. What she sent

Open each file and write what you see into the film's `PROMPT.md`:
- **Photos:** who and what is in them, faces or not, light, size in pixels, portrait or landscape. A 640 px photo is a card, never a full-bleed background.
- **Screenshots of AI tools or builds:** which tool, the exact prompt and answer text on screen, what the one thing to zoom on is. Crop out personal data (names, emails, other chats) before using.
- **Posters, flyers, event pages:** the facts on them (name, date, time, place, price, seats, prizes, partners, link), copied exactly.
- **Screen recordings:** the 2 to 4 seconds that show the move; the rest is cut.
- **A logo file:** if she sends one, it replaces the typeset wordmark in the lockup. Write that in `BRAND.md` "Assets on file".

## 3. Pasted text, links and notes

- An email or newsletter she pasted: its facts and its best lines (they are already in the GWAI voice).
- A link to an event page: read it if a tool can; if not, ask her to paste the details. Never guess what a page says.
- A Google Doc, Sheet or Drive folder: use a connector if one is available; otherwise ask for the files.

## 4. Enough to start

Stop once you can write the message in three short statements, name the type and style, and list every fact the type needs (with the ones still missing). Then run the interview ([interview.md](interview.md)) for what is left.
